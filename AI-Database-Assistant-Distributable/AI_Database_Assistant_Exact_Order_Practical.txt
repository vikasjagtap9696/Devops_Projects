AI DATABASE ASSISTANT
PRACTICAL IMPLEMENTATION GUIDE
============================================================

IMPORTANT
============================================================

Follow this document from STEP 1 to the END.

Do not jump directly to Lambda or API Gateway.

The project was built in this order:

LOCAL AI
   ↓
RDS MYSQL
   ↓
LAMBDA
   ↓
CLOUDFLARE TUNNEL
   ↓
API GATEWAY
   ↓
FRONTEND
   ↓
S3 + CLOUDFRONT (OPTIONAL PUBLIC DEPLOYMENT)

Project architecture:

User Browser
      |
      v
Frontend
      |
      v
API Gateway
      |
      v
AWS Lambda
      |
      +---------------------> RDS MySQL
      |
      v
Cloudflare Tunnel
      |
      v
Local FastAPI AI Gateway
      |
      v
Ollama
      |
      v
Qwen3:14b

STEP 1 - CREATE THE PROJECT FOLDER

4. IMPORTANT:

------------------------------------------------------------

Lambda
   ↓
Cloudflare HTTPS URL
   ↓
FastAPI
   ↓
Ollama
   ↓
Qwen3:14b
   ↓
Generated SQL
   ↓
FastAPI
   ↓
Lambda

STEP 44 - UNDERSTAND LAMBDA
------------------------------------------------------------

Lambda performs these tasks:

1. Reads the user's question.
2. Connects to RDS.
3. Reads database schema.
4. Reads foreign-key relationships.
5. Sends question + schema to FastAPI.
6. Receives generated SQL.
7. Validates the SQL.
8. Allows only SELECT.
9. Executes the SELECT query.
10. Returns the results.

------------------------------------------------------------

   user question

------------------------------------------------------------

Only:

   SELECT

   INSERT
   UPDATE
   DELETE
   DROP
   ALTER
   TRUNCATE
   CREATE
   REPLACE
   GRANT
   REVOKE


STEP 103 - LAMBDA EXECUTES SQL
------------------------------------------------------------
