*****S3 Metadata and Athena*****
===========================================
**Amazon S3 Metadata**:
--------------------

	Amazon S3 Metadata provides automatically generated metadata about objects stored in an S3 bucket.
	It helps users discover, query, analyze, and track S3 objects without manually scanning the bucket.

	. Automatically collects metadata about S3 objects.
	. Stores metadata in managed Apache Iceberg tables.
	. Metadata can be queried using Amazon Athena.
	. Provides near real-time information about objects.
	. Useful for data discovery, auditing, and analytics.
	
#Important Metadata Information:

	S3 Metadata can provide information such as:
     .Bucket name
	 .Object key / file name
	 .Object size
	 .Last modified date
	 .Version information
   	 .Encryption information
	 .Object status and other attributes

#S3 Metadata Tables:

	There are three important tables:

	1. Journal Table:
	Tracks changes to S3 objects.
	Use: Auditing, security, and compliance.

	2. Live Inventory Table
	Contains the latest metadata for objects in the bucket.
	Use: Object discovery and analytics.

	3. Annotation Table:
	Contains annotations associated with objects.
	Use: Search, discovery, and analytics.
	
**Amazon Athena**:
===================
	.Amazon Athena is a serverless SQL query service that allows users to analyze data stored
	in Amazon S3 without managing servers or databases.
	.It does not require servers or infrastructure management.	
		
#What is Amazon Athena?
	 .Serverless query service from AWS.
	 .Uses SQL to query data.
	 .Can directly query data stored in Amazon S3.
 	 .No database server installation or management required.
	 .Supports data analysis and reporting.
			
#How Athena Works:

		Data stored in S3
        	  ↓
		AWS Glue Data Catalog
		   	  ↓
		Amazon Athena
		      ↓
		SQL Query
		      ↓
		Query Results
				
    .Athena reads the data from S3 and executes SQL queries against it.
 
#Supported Data Formats:
		.CSV
		.JSON
		.Parquet
		.ORC
		.Avro
		.Apache Iceberg tables
	
#Advantages of Athena:
	.Serverless — no infrastructure to manage.
	.SQL-based — easy for users familiar with SQL.
	.Directly queries data in S3.
    .Integrates with AWS Glue Data Catalog.
	.Supports multiple data formats.
	.Suitable for data analysis and reporting.
	.Pay based on data scanned by queries.

#AWS Glue Data Catalog:

    .Athena uses the AWS Glue Data Catalog to store table definitions and schemas.	
	   
	Example:
	   
	    Database
            ↓
        employees table
            ↓
        Columns:
          id
          name
          department
	      salary
